Setup Required

Fill in your Azure App Registration details in js/onedrive-config.js before using the admin panel.

const ONEDRIVE_CONFIG = {
  clientId: 'YOUR_CLIENT_ID',  ← paste your App ID here
  tenantId: 'common',
  folderPath: 'ProductSelector',
  productsJsonUrl: ''
};

Steps to get your Client ID (one-time, ~10 min):

  1. Go to portal.azure.com → Azure Active Directory → App registrations
  2. Click New registration → Name it "ProductSelector Admin" → Register
  3. Copy the Application (client) ID and paste it as clientId above
  4. In the app: go to Authentication → Add platform → Single-page application
  5. Set redirect URI to:
  6. Go to API permissions → Add a permission → Microsoft Graph → Delegated
    Add both Files.ReadWrite and User.Read

  📁 datasheets/     — PDF datasheets
