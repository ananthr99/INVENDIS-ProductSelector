Data Migration Tool

Run this once to copy all existing products from the JS files into your OneDrive folder as an Excel file (products.xlsx) and a public JSON file (products.json). After migration, use the admin panel to make changes.

Read before running This will create a ProductSelector/ folder in your OneDrive and upload all products. If you run it again, it will overwrite any changes made through the admin panel. Only run this once on a fresh setup, or when you intentionally want to reset data back to what is in the code.
